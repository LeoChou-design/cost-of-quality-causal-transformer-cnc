Full texts are not redistributed here (copyright belongs to the original
publishers/authors) — links are provided where a legitimate open-access copy

   Open access: https://arxiv.org/abs/1706.03762 — background for the

   [causal-transformer-cnc-design-principles](https://github.com/LeoChou-design/causal-transformer-cnc-design-principles)
